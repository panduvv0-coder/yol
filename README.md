# Basics to Linux

Welcome to the **Basics to Linux** educational repository! This repository is designed to help beginners step into the world of Linux and master essential terminal commands through clear, practical, and easy-to-follow documentation.

## How to Use

If you are new to Linux or the command line, start from the first guide in `docs/01-getting-started/`:

1. [What is Linux?](docs/01-getting-started/what-is-linux.md) - Learn what Linux is, why it's widely used, and understand Linux distributions.
2. [Terminal Basics](docs/01-getting-started/terminal-basics.md) - Understand the terminal, command prompt components, and basic shell syntax.
3. [Basic Linux Commands](docs/01-getting-started/basic-commands.md) - Explore fundamental commands for navigation, file management, permissions, processes, and more.

Work through the sections sequentially and practice running the commands on your own Linux environment or terminal.

## Table of Contents

- `docs/01-getting-started/` - Introduction to Linux, terminal basics, and fundamental commands.
- `docs/02-file-system/` - Deep dive into the Linux filesystem hierarchy and path navigation.
- `docs/03-text-processing/` - Working with text files, redirection, and pipes.
- `docs/04-user-management/` - Managing users, groups, and permissions.
- `docs/05-permissions/` - Detailed permissions management and file access control.
- `docs/06-process-management/` - Monitoring, managing, and backgrounding system processes.
- `docs/07-package-managers/` - Installing and updating software across Linux distros (`apt`, `yum`/`dnf`, `pacman`).
- `examples/` - Practical examples and sample reference files.
- `scripts/` - Helpful shell scripts for learning automation.

## Contribution Guide

Contributions are welcome! If you would like to contribute:

1. **Fork and Clone**: Fork this repository and clone it to your local machine.
2. **Follow Conventions**: Read [AGENTS.md](AGENTS.md) to understand formatting and documentation guidelines:
   - Keep explanations simple and beginner-friendly.
   - Use `##` (H2) for sections and `###` (H3) for commands.
   - Place all code examples inside `bash` code blocks.
   - Note distribution differences where relevant.
3. **Submit a Pull Request**: Create a branch for your changes and open a pull request describing your additions or fixes.
