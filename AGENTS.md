# AGENTS.md

## Repository Overview

This repository contains Linux tutorial documentation designed to help beginners learn Linux and terminal commands step-by-step.

## Conventions & Rules

## General Structure
- **Docs-only Repository**: All educational material is written in Markdown files.
- **Beginner-Friendly**: Keep language simple, clear, and easy to understand. Assume the reader is completely new to the command line interface (CLI).

## Formatting Guidelines
- **Heading Levels**:
  - Use `##` (H2) for major sections within documentation files.
  - Use `###` (H3) for specific commands or sub-topics.
- **Command Formatting**:
  - Every command example must be formatted inside a `bash` code block.
- **Distribution Differences**:
  - Prefer distro-agnostic commands and explanations.
  - When referencing package managers or distro-specific behaviors, note relevant differences across distributions (e.g., Ubuntu/Debian `apt`, RHEL/Fedora `yum`/`dnf`, Arch `pacman`).
